GitHub は、世界中のコードが集まる場所

GitHub は、プログラム（コード）を置いておくための場所です。コードは「リポジトリ」という置き場所に保存されて、世界中の人が見たり、自分のパソコンに持ってきたりできます。

ただ保存するだけではありません。変更の履歴が残るので、「いつ・誰が・何を変えたか」が分かります。間違えても前の状態に戻れるので、安心して直していけます。

そして、みんなで同じコードを育てていけるのが GitHub の大きな特徴です。一人で作る小さなプログラムも、大勢で作る大きなプロジェクトも、ここに集まっています。
